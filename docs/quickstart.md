# Quickstart

Follow these steps to get started:

## 1. Clone the Repository

```bash
git clone https://github.com/shivanshsethios/Mintlify-docs.git
cd Mintlify-docs
```

## 2. Install Dependencies

```bash
npm install
```

## 3. Run Development Server

```bash
npm run dev
```

Your documentation will be available at `http://localhost:3000`.

## 4. Edit Documentation

Edit the files in the `docs/` folder to customize your documentation. Changes will be reflected instantly in your browser.

## 5. Deploy

When ready to deploy:

```bash
npm run build
```
