# Features Overview

## Documentation Made Easy

Mintlify provides a simple way to create beautiful documentation with:

- **Markdown Support**: Write your documentation in familiar Markdown
- **Dark Mode**: Automatically supported with custom theming
- **Search**: Built-in full-text search across your docs
- **API Documentation**: Seamless integration with API references
- **Mobile Responsive**: Works great on all devices
